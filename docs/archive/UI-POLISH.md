# 任务：美化 cc-manage 的 UI（前台 index.html + 后台 admin.html）

## 背景

两个页面（`public/index.html` 前台看板、`public/admin.html` 后台）功能都对，
但视觉上**没打磨过**。下面是设计师视角的具体缺陷清单，请逐条修掉。

**设计参照**：Linear / Vercel 的克制感 + komari 的樱花粉点缀。
保持现有樱花主题基因（`--accent: #e8668a`），但把执行水准拉上去。

---

## 一、致命伤：布局（先修这个）

### 1.1 主卡片只占左 1/3，右侧大片死白
**现状**：`main` 是居中列，但账号卡片只有一张，撑不满 → 右边空一大片，
看起来像"内容没加载出来"。
**修**：
- 账号卡片网格改为**自适应铺满**：`grid-template-columns: repeat(auto-fit, minmax(420px, 1fr))`
- 只有 1 个账号时，卡片**横跨整行**（不要让网格把它压到左边）
- 账号卡片内部改**双栏布局**（左：账号信息+余额；右：三个进度条），
  宽度够时并排，窄屏堆叠

### 1.2 对齐漂移（最容易被察觉的"业余感"）
**现状**：hero 内边距 ~28px、卡片 ~16px、KPI ~14px → 左边缘各差几像素。
**修**：定义**统一栅格**，所有内容块左边缘落在**同一条竖线**上：
```
--page-max: 1280px;      /* 内容最大宽度 */
--gutter: 24px;          /* 页面左右内边距 */
--card-pad: 20px;        /* 所有卡片统一内边距 */
```
hero / KPI 行 / 账号卡 / 页脚，**统一用 `--gutter` 对齐**，内部一律 `--card-pad`。

### 1.3 建立海拔阶梯（现在卡片和背景糊在一起）
定义三档表面 + 可见描边：
```
亮色主题：
--surface-0: #f8f6f9;   /* 页面底 */
--surface-1: #ffffff;   /* 卡片 */
--surface-2: #faf8fc;   /* 卡片内嵌区块 / hover */
--border: #e8e0f0;      /* 标准描边（要看得见）*/
--border-strong: #d8cce4 /* 需要强调的边界 */

暗色主题：
--surface-0: #17111c;
--surface-1: #221a29;   /* 与底拉开明显差异 */
--surface-2: #2b2133;
--border: #3d3046;      /* 比现在亮，要能看清 */
--border-strong: #4d3d58;
```
**要求**：卡片描边在两种主题下都**肉眼可见**；卡片与页面底色差异足够。

---

## 二、信息层次（现在全平）

### 2.1 Hero 区：把主角还给「余额」
**现状**：最大的字是实时时钟（48px），余额被压成小字 —— 本末倒置。
**修**：
- **余额数字**成为全页最大字号（clamp(40px, 6vw, 64px)），
  带 `font-variant-numeric: tabular-nums`
- 时钟**降级**为小字（14-16px），放 hero 右侧或页脚，别再抢戏
- 问候语保持中等字号（24-28px），粉色
- 「累计 token」等信息用小字跟在余额下方，形成清晰的主次

### 2.2 KPI 行：给语义色 + 削减高度
**现状**：6 个数字同色同重，错误数不显眼，0 值占满权重。
**修**：
- **错误数**：>0 时用 `--danger` 红色；=0 时用 `--text-tertiary` 灰（弱化）
- **可用数**：< 总数时用 `--warning` 黄
- **在途请求**：>0 时用 `--accent` 粉
- 数字与标签的字号差拉开（数字 24-28px / 标签 11-12px 且加 `letter-spacing: .02em`）
- 卡片**高度收紧**（去掉多余的上下留白，`padding: 14px 16px`）
- 给每个 KPI 加**极小图标**（内联 SVG，不是 emoji），提升扫读性

### 2.3 账号卡片内部
- **ID 行**：`<keyId>` 和 `<keyPrefix>…` 之间用 `·` 分隔，
  **不要多余空格**，且**不要从中间截断**（用 `text-overflow: ellipsis` 整体省略）
- **进度条**：
  - 行与行之间间距拉大（`margin-bottom: 14px`），标签与自己的条之间**紧凑**
  - 条高从 6px → **8px**，圆角胶囊
  - 轨道颜色要看得见（用 `--surface-2` 或半透明）
  - 百分比数字用等宽字体，**右对齐**
- **底部标签统一**：全部做成 pill（现在"在途 0""套餐 xxx"是裸文字，很乱）
- 状态点（绿色小圆）**加文字标签**，别让人猜

---

## 三、可读性（无障碍）

- 所有小字（11-13px）的对比度**必须 ≥ 4.5:1**（用 `--text-secondary`
  而不是更浅的色；页脚也要能看清）
- 用 `color-scheme: light dark` 让浏览器原生控件跟随主题
- 焦点态：所有可交互元素要有**可见的 focus ring**
  （`outline: 2px solid var(--accent); outline-offset: 2px`），别用 `outline: none`
- `@media (prefers-reduced-motion: reduce)` 下关掉花瓣和过渡动画

---

## 四、装饰（现在像 bug 不像设计）

**花瓣**：
- **禁止在视口边缘被裁切** —— 生成时约束在 `[0, 100vw]` 内，
  或给容器 `overflow: hidden` 并且花瓣从外部飘入
- 透明度降低（0.15-0.25），尺寸更小（4-7px），别抢内容
- 数量 8-12 片，`pointer-events: none`，`z-index: 0`（内容在它上面）
- 花瓣形状用 CSS `border-radius: 50% 0 50% 50%` 之类的花瓣形，别用圆点

**背景**：
- 加**极淡的径向渐变**（从左上角粉色光晕渐变到透明），
  但**不要压在文字下方**造成对比度下降（用 `::before` 且 `z-index: 0`）
- 或者干脆用 `--surface-0` 纯色 + 花瓣，克制一点

---

## 五、排版系统

定义**模块化字阶**（别再随便定字号）：
```
--fs-xs: 11px;    /* 标签 */
--fs-sm: 13px;    /* 次要文字 */
--fs-base: 14px;  /* 正文 */
--fs-md: 16px;    /* 小标题 */
--fs-lg: 20px;    /* 区块标题 */
--fs-xl: 28px;    /* 问候语 */
--fs-hero: clamp(40px, 6vw, 64px);  /* 余额大数字 */
```
- 行高：正文 1.6、标题 1.25、大数字 1.0
- 中文字体栈保持 `-apple-system, "PingFang SC", "Microsoft YaHei"`，
  数字/ID 用 `ui-monospace, "SF Mono", Menlo, Consolas, monospace`
- 大号中文（问候语）加 `letter-spacing: .01em` 更透气

---

## 六、后台页面（admin.html）同样标准

后台是**表格为主**的管理界面，除了套用上面的 token，额外：
- 表格：表头 `--surface-2` 底 + 小字大写标签；行 hover 高亮；行高 44-48px
- 按钮分级：主操作（粉底白字）/ 次操作（描边）/ 危险操作（红描边，hover 才填红）
- 危险操作（删除）hover 时才变红，别一直红着
- 表单输入框：统一 36px 高、圆角 8px、focus 态粉色描边
- 日志列表：等宽字体、时间戳弱化、级别用色点标记

---

## 七、硬约束（不能破）

1. **零外部依赖**：不许 CDN / 字体外链 / npm 装包。图标用**内联 SVG**
2. **单文件**：每个页面仍是单一 HTML（内联 style + script）
3. **86 个测试必须全绿**（`npm test`）。特别注意这些断言：
   - `test/gateway.test.mjs` 测试6：`GET /` 的 HTML 含 `cc-manage`、`5 小时窗口`、
     `本周窗口`、`本月周期`、`/api/status`
   - 测试32（已按新设计改写）：前台**不含** `id="key"` 输入框、不含 `sessionStorage`、
     含 `href="/admin"`、含 `apiFetch('/api/status')`、不含 `Authorization: Bearer`
   - `test/auth.test.mjs`：后端行为，不受 UI 影响
   ➜ **如果某个断言因为 UI 改写而必须调整，先停下来在回复里说明，不要擅自改测试**
4. **不改后端**（`gateway.mjs` / `src/*`）—— 这是纯 UI 任务
5. 亮/暗双主题都要测；响应式（375px / 768px / 1440px）都要正常
