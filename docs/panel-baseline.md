## 用户反馈的「重复多余」（实测清单，B24/B25 要逐条消掉）

1. **累计 token 出现两次**：Hero 右上角 + 「总请求」卡副文案，**完全相同**
2. **账号口径重复三处**：Hero「网关状态 可用 3/4」≈ KPI「账号数 4 + 可用 3 + 不可用 1」，
   而 `3/4` 本身是后两者的**派生值**
3. **「账号数 4 = 可用 3 + 暂停中 0 + 不可用 1」** 是后三张卡之和；
   且 **「暂停中 0」是零值卡** —— 占一个槽位、零信息量
4. **时间戳近乎重复**：脚注「更新于 12:06:57」与右上角「12:07:00」只差 3 秒
5. **样本数说两遍**：「数据收集中 253/288」与「共 253 个样本」
6. **「刷新额度」按钮与「额度自动刷新：有请求时每 1 分钟」自相矛盾/冗余**
7. **额度数字三处语义重叠**：`16.66` 剩余 / `16.76` 月度 / `58.1%` 已用 —— 口径不易区分
8. **图例三项里两项在图上几乎不可辨认**（请求数灰线、错误数红点）：图例与图形信息不匹配，
   属装饰性冗余

> 注：第 8 条是**暗色主题下**的观感。判定"能不能辨认"要按 `panel-conventions.md`
> 的图元探针实测，别只凭截图；但"图例列了三项、其中两项看不出"这个**信息冗余**的判断成立。
